title: Highlighting
description: Snippets are markdown-marked text, not trusted HTML.

Highlighting is **off** until you pass `highlight` with one or more
searchable field names.

```ts
const result = await index.search("sqlite", { highlight: ["title"] });
result.hits[0]?.formatted?.title;
```

Default markers (`HighlightMarkers`):

```ts
{ start: "**", end: "**", ellipsis: "…" }
```

Override per request:

```ts
await index.search("sqlite", {
  highlight: ["title"],
  highlightMarkers: { start: "[", end: "]", ellipsis: "..." },
});
```

Marker strings are capped at 16 code points. At runtime, an unknown highlight
field throws `SEARCH_QUERY_INVALID` with
`details.reason === "undeclared-highlight-field"`. A marker containing NUL
throws `SEARCH_QUERY_INVALID`; a marker over the length cap throws
`SEARCH_QUERY_LIMIT_EXCEEDED`.

Fuzzy fallback hits never receive `formatted` snippets. If you requested
highlight fields and fallback ran, the response includes warning
`highlight-unavailable-fuzzy`. See [typo tolerance](/guides/typo-tolerance).
