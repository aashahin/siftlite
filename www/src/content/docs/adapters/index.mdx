An adapter implements `SqlAdapter` (`query`, `execute`, `batch`,
`transaction`) plus `runtimeCapabilities`. Core never imports Bun, Node, D1,
or libSQL APIs.

| Package | Factory | Runtime |
| --- | --- | --- |
| `@siftlite/bun` | `bunSqliteAdapter(db)` | `bun:sqlite` |
| `@siftlite/node` | `nodeSqliteAdapter(db)` | `better-sqlite3` |
| `@siftlite/d1` | `d1Adapter` / `d1SessionAdapter` | Cloudflare D1 |
| `@siftlite/libsql` | `libsqlAdapter(wrapLibsqlClient(client), { kind })` | libSQL / Turso Cloud FTS5 |

Experimental Turso-native FTS lives under `experimental/` in the repo and is
**not** a stable backend. `@siftlite/libsql` is FTS5, not Tantivy.
